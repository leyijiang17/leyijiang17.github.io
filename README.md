# Leyi's Website

The personal website of Leyi Jiang, a PhD candidate at the Max Planck Institute of Molecular Cell Biology and Genetics in Dresden, working on topological data analysis for spatial sub-cellular biological data. It collects research papers, activities, projects, and choreography and dance.

Live at [leyijiang17.github.io](https://leyijiang17.github.io).

## Acknowledgements

This site started from [hugo-website](https://github.com/pmichaillat/hugo-website), a minimalist Hugo template for academic websites by Pascal Michaillat. The template builds on the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme by nanxiaobei and Aditya Telange.
